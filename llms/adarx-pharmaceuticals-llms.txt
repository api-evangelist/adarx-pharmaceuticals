# ADARx Pharmaceuticals

> ADARx Pharmaceuticals, Inc. is a clinical-stage biotechnology company in San Diego, California,
> developing next-generation RNA therapeutics — siRNA, RNA editing and proprietary targeted
> delivery — against hepatic and extrahepatic targets. ADARx runs no developer program and
> publishes no product API. The only machine-readable surfaces reachable without credentials are
> the WordPress REST content APIs behind www.adarx.com and stophae.com, catalogued below by API
> Evangelist.

**This file is an API Evangelist generation, not a provider artifact.** ADARx does not publish an
llms.txt; https://www.adarx.com/llms.txt and https://stophae.com/llms.txt both returned 404 on
2026-08-06.

## APIs

- [ADARx Pharmaceuticals Content API](https://www.adarx.com/wp-json): the anonymously readable
  WordPress REST API behind the corporate site. 46 press releases / clinical-trial listings /
  board-and-leadership biographies / publications, 18 corporate pages, a 105-item media library,
  six categories, cross-content search, an oEmbed 1.0 provider, and a Yoast SEO head renderer that
  returns the page's schema.org JSON-LD. Unlike most corporate WordPress installs, article bodies
  ARE populated in `content.rendered`.
- [ADARx STOP-HAE Trial Site API](https://stophae.com/wp-json): the WordPress REST API behind the
  STOP-HAE Phase 3 patient-recruitment site. Its distinguishing feature is a custom `clinic` post
  type carrying 50 trial-site records, readable anonymously — though the ACF payload that holds
  each site's address and contact is not projected into REST.
